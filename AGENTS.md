# AGENTS.md

Project memory lives in `agent-hub/` (verified, kept by Claude Code
workers). Read before working:

1. `agent-hub/NORTHSTAR.md` — what this project is for.
2. `agent-hub/doctrine/MEMORY.md` — exact test/build/lint commands. Copy
   them, never retype from memory.
3. `agent-hub/doctrine/domains/PROJECT.md` — invariants, Traps (known
   bugs, don't repeat them), Decisions with reasons.
4. `agent-hub/doctrine/features/INDEX.md` — find the one feature spec
   your change touches, open only that one.

Don't edit anything under `agent-hub/` — progress, specs and evidence
are written only through the Claude Code worker loop (`/todo`).
